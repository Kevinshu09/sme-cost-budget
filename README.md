# SME Cost Budget

`sme-cost-budget` is a conversational skill for small-business cost and budget control. It guides an owner through business-model intake, expense review, statement reconciliation, and a six-month cash-flow projection. It keeps user-provided figures, statement-derived figures, and unknown assumptions explicitly separated.

## Contents

- `SKILL.md` — the complete skill instructions.

## Use

Install or copy `SKILL.md` into an AI-agent environment that supports Markdown-based skills. Invoke it when you need a structured operating reference for cost control, budget planning, expense optimization, or cash-flow projection.

## Important limits

This is an operating-reference tool, not a formal financial document or tax, legal, investment, insurance, or employment advice. Review outputs and consult appropriately licensed professionals before making consequential decisions. Do not provide account passwords, verification codes, or identification numbers; use only the information necessary for the analysis.

The skill itself does not include telemetry or statement data. Data handling by the host AI product, connected services, or future modifications is outside this repository's control.
